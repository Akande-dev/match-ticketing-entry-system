# Final report outline (25-35 pages)
1. Introduction: problem, users, objectives, outcome table (met / partly / not met)
2. Process: Scrum, how it was adapted, evidence (pull requests, board)
3. Requirements and planning: stakeholders, FR/NFR, MoSCoW, estimates, risks
4. Models: use case, class, sequence, activity, state
5. Architecture and design: serverless style, components, ERD, patterns, SOLID module
6. Implementation: modules, coding standard, key decisions (transactions, signed QR, idempotent payments)
7. Prototype and progress: demo, plan versus actual
8. Quality and security: tests, coverage, static analysis, defects, STRIDE, OWASP, CI
9. Change and project management: CR-01, metrics
10. Evaluation: requirements traceability, non-functional results, limitations (no deployment, no load test, manual refunds payout, no MFA, offline scanning descoped)
11. Reflection
12. Conclusion and future work
Appendices: deliverables map (docs/README.md), test cases, user manual, glossary, references
