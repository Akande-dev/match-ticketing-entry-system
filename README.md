# Match Ticketing and Stadium Entry System

React + Firebase. Fans buy seats, get signed QR tickets; stewards validate them at the gate.

## Quick start

## Run the demo (Windows, no internet needed)
1. Install Node.js, Git and Java 21 (Temurin), then run `npm install`, `npm --prefix functions install` and `npm --prefix web install`.
2. Copy `functions/.env.example` to `functions/.env` and `web/.env.example` to `web/.env.local`.
3. Double-click `start-demo.bat`. The browser opens at http://localhost:5173 with clean demo data.
4. Log in with fan@demo.com, steward@demo.com, manager@demo.com or admin@demo.com (password `Demo1234!`).
See `docs/demo-guide.md` for the presentation script and `docs/README.md` for all project documents.
